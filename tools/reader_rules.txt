# reader_rules.txt —— 阅读器分卷/分章规则（**可随时替换，不用刷固件**）
#
# 放这里：/sdcard/m5ui/reader_rules.txt      （手机浏览器 http://<设备IP>/ 可直接上传/替换）
# 兜底  ：文件不在 / 格式不对 → 用 .so 里编进去的默认规则，并打一行日志说明用了哪份
# 生效  ：重新进入阅读器 app（page_init）时读一次；换文件后重进即生效，不用重启设备
#
# 格式：每行一条 <KEY><空格><值...>；# 开头是注释；空行忽略；不认识的 KEY 忽略（向前兼容）
# 第一行必须是版本行，用来挡住放错文件/格式漂移：
!reader-rules 1

# ── 标记字（决定级别）──
V 卷部篇集
C 章回
S 节

# ── 编号前缀（可多行；ASCII 与汉字数字都靠 D 表声明）──
P 第

# ── 数字形态：A=ASCII 0-9，H=下面这行给的汉字数字集合 ──
D A H
H 零〇一二三四五六七八九十百千两

# ── 独立关键字（整行独立即算，归为卷级；关键字后必须结束或跟分隔符）──
K 前传 序章 序言 楔子 引子 尾声 终章 后记 番外 外传 完本感言 上架感言

# ── 拒绝对：标记字紧跟这个字时判为正文（实测误判形态）──
#    回+合 = "第一回合"（打斗轮次）   集+团 = "第16集团军"
R 回 合
R 集 团

# ── 阈值 ──
L 30     # 标题行最大字数（正文里"第一回合，自己秘密抢先出击……"这类长句靠它挡）
G 2      # 同书候选数下限；低于它 → 整本不分章（判定不可靠宁可不给目录）

T 15

A 作者
B 《》
