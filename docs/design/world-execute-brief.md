# 《world.execute(me);》墨水屏 UI 设计说明书

## 一、 项目概述与设计基调
*   **项目背景**：基于歌曲《world.execute(me);》的赛博朋克意境。
*   **核心概念**：一个被困在低刷新率墨水屏设备里的“机器心脏”监控终端，以及一个等待被用户激活的“系统执行程序”。
*   **设计基调**：极简、冰冷、机械、程序化、绝对服从。
*   **用户交互**：用户通过点击按钮触发“执行程序”，系统将逐步释放控制权，最终完成任务（END OF LINE）。

## 二、 硬件与屏幕约束
*   **屏幕尺寸**：540px (宽) × 960px (高)，竖屏。
*   **显示特性**：单色（纯黑与纸白），无背光，无抗锯齿。
*   **刷新率限制**：模拟真实墨水屏极慢的物理刷新（约230ms一帧）。画面禁止平滑动画，必须呈现“瞬间跳跃”和“局部闪烁”的物理特征。

## 三、 视觉设计规范 (Visual Spec)
*   **颜色规范**：
    *   纸白（背景）：`#f2f2ee`
    *   墨黑（文字/线条）：`#0a0a0a`
    *   反色模式（执行状态）：黑底白字（背景 `#0a0a0a`，文字/线条 `#f2f2ee`）
*   **字体规范**：全系统强制使用等宽字体（如 `Courier New`, `JetBrains Mono`, `Fira Code`），字号偏小，字间距带感。
*   **纹理与材质**：
    *   全屏叠加墨水屏特有的1px交叉像素栅格纹理（水平与垂直方向）。
    *   心电图区域有10px网格背景，模拟医疗监护仪底层纸带。
*   **边框与圆角**：无圆角，全直角。使用硬朗的1px或2px实线。

## 四、 UI 布局与状态机
### 状态一：待机（待机监控）
*   **顶部状态栏**：左中右三个区域，分别显示 `SYS.WORLD`、当前时间（如 20:20）、电池电量（BAT 100%）。底部有线框分割。
*   **心电图监控区**：
    *   外框带细线边框。
    *   左上角标签：`// VITAL SIGNAL (TIME WINDOW 1s)`。
    *   **核心波形画布**：心电图波形区域，独立包裹，内部包含闪烁层。
    *   下方日志：`[SYS] HEART RATE: -- BPM`、`[SYS] BEATS IN LAST 1s: --`、`[WARN] HEART IS A BOMB`。
*   **交互提示区**：大写等宽字体 `> AWAITING COMMAND_`（光标闪烁），副标题 `// 等待被使用`。
*   **执行按钮**：底部固定，黑底白字，高度 90px，文字 `EXECUTE`。

### 状态二：执行（程序执行）
*   全屏反色（黑底白字）。
*   显示终端日志流（如 `> INIT EXECUTION PROTOCOL... [OK]`），逐行打印。
*   底部显示进度条（使用 `▓` 和 `░` 字符模拟），以及百分比数字。

### 状态三：终局（结束与重启）
*   屏幕正中显示 `END OF LINE`。
*   底部小字 `TAP TO REBOOT`，点击屏幕任意位置可重新启动系统。

## 五、 核心算法与交互逻辑（重点）

### 1. 心率生成引擎（模拟真实生命体征）
*   **目标心率漂移**：目标心率（60~90 BPM）不是固定的，而是随机缓慢游走。
*   **呼吸调制**：叠加一个3秒周期的正弦波，模拟呼吸对心率的微调（吸气微快，呼气微慢）。
*   **生理惯性**：当前心率平滑追随目标心率。
*   **心率变异性 (HRV)**：每次心跳的间隔加上随机的生理噪声。
*   **偶发早搏**：有 5% 的概率触发早搏，间隔突然缩短至 0.65 倍，紧接着出现较长代偿间歇。

### 2. 时间窗口映射引擎（决定波形如何滚动与截断）
*   **走纸速度**：固定为 `60px / 秒`。
*   **波形物理宽度**：一个完整的 P-QRS-T 波形，物理宽度固定为 `63px`（约耗时1.05秒）。
*   **时间映射**：画面的 X 轴坐标与时间严格绑定。屏幕显示过去9秒（540px / 60px/s）的数据。
*   **截断与续画逻辑**：
    *   **禁止平滑滚动**。屏幕必须以 **1秒为周期**（1000ms）批量刷新。
    *   每次刷新时，计算当前时间点 `now`，并截取当前时间之前的9秒作为可见窗口。
    *   **关键表现**：如果当前时间 `now` 恰好落在某个心跳的持续时间中间，屏幕上只绘制这个心跳的**前半部分**。后半部分会在下一次刷新（1000ms后）时，随着历史波形左移，被自然地“续”在屏幕上。
    *   波形严格按照时间轴排列，心率快时波形自然靠得紧密，心率慢时波形则拉得疏远。

### 3. 墨水屏局部刷新与波形重绘逻辑（核心硬件交互）
*   每次刷新时，触发一次 **230ms 的闪烁**（黑 -> 白 -> 黑 -> 消失）。
*   该闪烁层必须仅覆盖**波形画布区域**，不影响页面上方的标题文字、下方的系统日志以及按钮。
*   闪烁结束后，瞬间完成波形的重绘。
*   **波形重绘与残影消除机制（原话缩进写入）：**
    *   Fast的是波形的刷新档位啊，这个你别管，原话，缩进写进去就行。
    *   质量档位指的就是fast/fastest/text12/gc13等刷新波形。
    *   波形等它的X的坐标快要满了，就是接近那个外面的方框的时候，就让波形所涉及的一整个矩形区域重新用质量档位把它调整为背景，这样就可以消除它的阴影，然后再重新绘制心跳波形。
